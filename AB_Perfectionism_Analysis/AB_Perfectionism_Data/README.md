# Data files

Participant-level data are not included in this repository. Deidentified data may be obtained from the corresponding author upon reasonable request, subject to applicable ethical, institutional, consent, and data-protection requirements.

Researchers who receive the data should place the supplied files in this directory without changing their filenames. The analysis documents and preparation scripts use paths relative to the repository root.

Expected files:

- `questionnaires_study1.1.xlsx`
- `questionnaires_study1.2.xlsx`
- `rt_study1.xlsx`
- `et_study1_500to5500.xlsx`
- `questionnaires_study2.1.xlsx`
- `questionnaires_study2.2.xlsx`
- `questionnaires_study2.3_1.xlsx`
- `questionnaires_study2.3_2.xlsx`
- `questionnaires_study2.3_3.xlsx`
- `questionnaires_study2.xlsx`
- `rt_study2.xlsx`
- `et_study2_500to5500.xlsx`

The R Markdown documents provide the complete preprocessing workflow. The standalone preparation scripts reproduce the analysis-ready objects required by the supplementary analyses.
